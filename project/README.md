# FluxBB Modernization Project

## Обзор

FluxBB — форумный движок, форк PunBB. Текущая кодовая база — `fluxbb/fluxbb` v1.5.11,
написанная на PHP 5.6.4+ с процедурным стилем, файловым кешированием и собственной
шаблонной системой на PHP.

**Цель:** Переписать легаси на современный стек (PHP 8.4+/8.5, Symfony components/Flarum-style,
современные практики), сохранив бизнес-логику, но восстановив доменные шрамы
из issue-трекера.
